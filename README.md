## 🧩 Update — Battle UX, карта и анимации (28.04.2026)
### ⚔️ Боевая система

* Добавлен корректный **переход: карта → бой → карта**
* Исправлена инициализация через **VContainer (LifetimeScope + Bootstrap)**
* Устранены ошибки `NullReference` и проблемы с зависимостями

---

### 🗺️ Карта

* Реализована **структура карты через MapSO**
* Поддержка:

  * разные типы узлов (бой, событие, костёр, магазин, элитка, босс)
  * кастомные переходы между нодами
* Добавлены **иконки узлов (pixel art)**
* Переделан `MapNodeView` под реальные спрайты (без текстовых заглушек)

---

### 🎴 Рука карт (ключевой блок)

* Убран `HorizontalLayoutGroup` (он ломал всё, как обычно)
* Сделан **ручной layout через код**
* Реализовано:

  * позиционирование в диапазоне `[-500; 500]`
  * корректное распределение при любом количестве карт
  * фикс бага с "дублированием карт" (раньше становилось 9 вместо 4)

---

### 🎞️ Анимации (DOTween)

Добавлена полноценная цепочка:

#### ▶️ Розыгрыш карты:

```
клик
→ карта взлетает вверх
→ применяется эффект
→ карта летит в сброс
→ уменьшается
→ рука пересчитывается
```

#### ❌ Недостаточно энергии:

```
клик
→ тряска карты
→ сообщение "Недостаточно энергии"
→ без анимации розыгрыша
```

#### ⏹️ Конец хода:

```
нажатие кнопки
→ все карты по очереди улетают в сброс
→ ход врага
→ новая рука
```

### 🎨 Визуал
