# RoadOfAsh

Карточный roguelite deckbuilder в мрачной сказочной стилистике.

## 📌 Текущий прогресс

### ⚔️ Бой

- Пошаговая система боя (энергия, рука карт, конец хода)
- Применение эффектов карт:
  - Урон
  - Блок
  - Яд
  - Слабость
  - Добор карт
  - Энергия
- Система искажения (DistortionService)
- Поддержка corrupted-эффектов карт

### 🧠 Враг

- Добавлена система намерений (Enemy Intent):
  - Attack
  - Block
  - Buff
- Намерение отображается в UI
- Логика выполнения намерения отделена от UI

### 🛡️ Блок

- Реализован блок у игрока и врага
- Блок корректно уменьшает входящий урон
- Блок сбрасывается в начале хода

### ☠️ Статусы

- Реализованы:
  - Яд (Poison)
  - Слабость (Weak)
- Отображение через иконки (StatusIconView)
- Значения отображаются поверх иконок

### 🧾 Tooltip система

- Плашка описания статуса (StatusTooltipView)
- Общая система показа (StatusTooltipSystem)
- Появляется рядом с выбранной иконкой
- Закрывается кликом в любое место

### 💥 Визуальные эффекты

- Всплывающий текст:
  - Урон
  - Блок
  - Яд
- Реальные значения (с учётом блока)

### 🎁 Награды

- Система наград после боя:
  - Карты
  - Лечение
  - Золото
- RewardItemView с разным отображением типов наград

### 🧩 Архитектура

- Разделение:
  - Domain (логика)
  - Presentation (UI)
- Используется VContainer (DI)
- BattleService не зависит от UI
