# RoadOfAsh / СКАЗКА ВРЁТ

Карточный roguelite deckbuilder в мрачной славянской сказочной стилистике.

Игрок управляет Иваном, который проходит через живую сказку. Сказка врёт: карты могут искажаться, враги заранее показывают намерения, а игрок постепенно накапливает **Понимание сказки**, чтобы лучше сопротивляться хаосу.

## Главная механика

### Искажение

Каждая карта может быть искажена. При искажении карта применяет альтернативный эффект.

Пример:

- обычный эффект: нанести 5 урона
- искажённый эффект: нанести 3 урона

Искажение бывает двух типов:

1. **Случайное искажение**
   - зависит от `CorruptionChance` карты
   - снижается через `Понимание сказки`
   - полностью не исчезает

2. **Принудительное искажение**
   - вызывается врагами через `DistortNextCard`
   - работает даже при высоком понимании

---

## Понимание сказки

`Понимание сказки` — отдельная шкала прогресса внутри рана.

Чем выше понимание:

- тем реже случайные искажения
- тем сильнее сопротивляется сказка
- враги становятся опаснее

Понимание не отключает механику искажения полностью. Сказка всё ещё врёт, просто игрок лучше понимает её правила.

## Tutorial flow

Реализована отдельная обучающая сцена.

Обучение объясняет:

1. энергию
2. стоимость карт
3. атаку
4. намерение врага
5. блок
6. конец хода
7. искажение
8. понимание сказки
9. награду после боя

Реализовано:

- `TutorialBattleFlow`
- `TutorialPanelView`
- `TutorialHighlightView`
- подсветка нужного UI-элемента
- подсветка конкретной карты атаки
- подсветка конкретной карты блока
- блокировка неправильных карт
- блокировка End Turn до нужного шага
- фиксированная tutorial-колода
- отключение случайного искажения в tutorial
- tutorial reward после победы

В обычной `BattleScene` tutorial flow отсутствует.  
В `TutorialBattleScene` объект `TutorialBattleFlow` есть.

## Реликвии

Реализована базовая система реликвий.

Есть:

- `RelicSO`
- `RelicPoolSO`
- `RelicEffectType`
- `IRelicService`
- `RelicService`
- `RelicBarView`
- `RelicIconView`

Реликвии хранятся в:

- `PlayerState.Relics`

Реликвии могут:

- блокировать первое искажение за ход
- давать блок в начале хода
- давать золото после победы
- лечить после победы

Примеры реликвий:

### Оберег правды

- Id: `truth_charm_01`
- эффект: первый раз за ход предотвращает искажение карты

### Кора-оберег

- Id: `bark_charm_01`
- эффект: в начале каждого хода даёт блок

### Золотой зуб

- Id: `gold_tooth_01`
- эффект: после победы даёт золото

### Живой корень

- Id: `living_root_01`
- эффект: после победы восстанавливает HP

## Рефакторинг BattleScreen

`BattleScreen` больше не является бог-классом.

Логика вынесена в отдельные flow-классы:

- `BattleSetupFlow` — старт боя, выбор врага, подготовка колоды
- `BattleHandFlow` — инициализация руки и клики по картам
- `BattleCardPlayFlow` — разыгрывание карт
- `BattleTurnFlow` — конец хода
- `BattleFeedbackFlow` — визуальные боевые эффекты
- `BattleUiRefreshFlow` — обновление HUD, руки, статусов, реликвий и понимания
- `BattleRewardFlow` — награды после боя
- `BattleResultFlow` — победа, поражение, continue
- `BattleAftermathFlow` — послебоевые эффекты реликвий
- `BattleSceneFlow` — переходы между сценами

`BattleScreen` теперь выполняет роль координатора.
